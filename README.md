# Bedrock Voice Bridge

Talk with other players on supported Minecraft Bedrock multiplayer servers.

## Install

1. Install the **required Bedrock Voice Bridge add-on** on a compatible server/world.
2. Install the Bedrock Voice Bridge app from the [Releases page](https://github.com/Tvmanisback/Bedrock-Voice-Bridge/releases).
3. Allow microphone access in the app and pair it with the supported server.
4. In Minecraft, type `!voice` in chat to open the add-on's voice menu.

## What each part does

- **Required Bedrock add-on:** in-game voice menu, mute/unmute controls, voice on/off, and preferences.
- **Companion app:** microphone access and the audio connection only.

**Coming soon:** support for worlds outside multiplayer servers.
